GUÍA PARA SUBIR LA WEB A INTERNET (PRODUCCIÓN)
==============================================

Cuando quieras que tu web esté funcionado de verdad (sin la terminal negra) y que los correos lleguen a tu Gmail, sigue estos pasos:

1. ¿DÓNDE ALOJAR LA WEB?
------------------------
Necesitas un "Hosting" que soporte Node.js. Opciones gratuitas/baratas recomendadas:
- Render.com (Muy fácil, tiene plan gratuito)
- Railway.app (Muy bueno, da crédito inicial)
- Vercel (Solo para el frontend, el backend necesitaría ser una "Serverless Function")

Yo recomiendo **Render.com**.

2. PREPARAR EL CÓDIGO (IMPORTANTE)
----------------------------------
Antes de subirlo, tienes que cambiar el `server.js` para usar GMAIL de verdad.

A) Borra la línea que acabo de añadir arriba del todo:
   `process.env.NODE_TLS_REJECT_UNAUTHORIZED = '0';`
   (¡Nunca dejes esto en una web real insegura!)

B) Cambia la configuración de Nodemailer en `server.js`.
   Borra todo el bloque `initEmailSystem()` y el `transporter` actual, y pon esto:

   // ---------------------------------------------------------
   const transporter = nodemailer.createTransport({
       service: 'gmail',
       auth: {
           user: process.env.EMAIL_USER, // Usaremos variables de entorno por seguridad
           pass: process.env.EMAIL_PASS
       }
   });
   // ---------------------------------------------------------

3. CONFIGURAR LAS VARIABLES EN EL HOSTING
-----------------------------------------
En el panel de control de Render/Railway, verás una sección llamada "Environment Variables".
Ahí tienes que añadir:

- EMAIL_USER: diegocabellobautista06@gmail.com
- EMAIL_PASS: (La contraseña de aplicación de Google que generaste)

4. NO OLVIDES EL PUERTO
-----------------------
En `server.js`, la línea `const PORT = 3000;` debería ser:
`const PORT = process.env.PORT || 3000;`
Así el hosting decide qué puerto usar.

¡Suerte con el lanzamiento!
