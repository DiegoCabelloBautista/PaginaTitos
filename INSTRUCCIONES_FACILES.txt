SOLUCIÓN SIN BACKEND (FORMSPREE) - ¡MUCHO MÁS FÁCIL!
======================================================

He adaptado el código para que NO NECESITES servidor, ni Render, ni contraseñas.

PASO 1: Consigue el código de Formspree
1. Entra en https://formspree.io/register y regístrate (es gratis).
2. Crea un "New Form" y ponle un nombre (ej: "Contacto Titos").
3. Pon tu email: diegocabellobautista06@gmail.com
4. Te darán una URL que se ve así: https://formspree.io/f/xnqyjzby

PASO 2: Ponlo en tu web
1. Abre el archivo `contacto.html`.
2. Busca la línea donde pone:
   action="https://formspree.io/f/TU_CODIGO_AQUI"
3. Cambia `TU_CODIGO_AQUI` por el código que te dio Formspree.

PASO 3: Subir la web
1. Sube los cambios a GitHub:
   git add .
   git commit -m "Usando Formspree"
   git push

2. Activa GitHub Pages (¡Gratis y fácil!):
   - Ve a tu repositorio en GitHub > Settings > Pages.
   - En "Source", elige "main" y guarda.
   - En unos segundos te darán un link tipo: https://diegocabellobautista.github.io/PaginaTitos

¡Y ya está! Tu web estará online y el formulario funcionará sin complicaciones.
