¡AVISO IMPORTANTE SOBRE GITHUB PAGES!
===================================

Al mover los archivos a la carpeta `frontend`, GitHub Pages dejará de funcionar automáticamente.
Para arreglarlo:

1. Ve a GitHub > Settings > Pages.
2. Comprueba si te deja elegir la carpeta `/frontend` como "Source".
   - Si GitHub NO te deja elegir `/frontend` (a veces solo deja `/` o `/docs`), tendrás que usar otra solución.

SOLUCIÓN RECOMENDADA (RENDER):
Como ya tienes un backend, lo mejor es subir TODO el proyecto a Render.com (como te expliqué en la GUÍA DE PRODUCCIÓN).
Render detectará `backend/server.js` y servirá tu frontend automáticamente.

SI QUIERES PROBAR EN LOCAL:
cd backend
node server.js
